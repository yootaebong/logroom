# 00 · Product

## 한 줄 정의

일이 벌어지는 모든 곳(AI 세션·SaaS·수동 기록)의 활동을 자동 캡처하는, **로컬 온리 작업 기록기**.
AI 세션·SaaS 업무 흔적을 자동 캡처해 **병렬 스트림 타임라인**과 **오늘의 요약**으로 보여준다.

## 문제 정의

- 일은 AI 세션뿐 아니라 Slack 스레드, Linear 티켓, Figma 코멘트 등 **여러 곳에서 동시에** 벌어진다.
- 각 툴은 자기 안의 기록만 남길 뿐, "지금 뭘 하는 중인지", "오늘 내가 무엇을 했는지"를 **통합해서 보여주는 곳은 어디에도 없다.**
- 각 툴의 기록은 파편화돼 흩어져 있고, 회고·보고·자기점검이 어렵다.
- 기존 타임트래커는 "앱 사용 시간"만 재고, **실제 활동의 내용(프롬프트/메시지/티켓/코멘트)** 은 못 잡는다.

## 차별점 (왜 이게 특별한가)

1. **딥 캡처** — 앱 사용 시간이 아니라 활동의 **내용**(프롬프트·응답·메시지·티켓·코멘트)을 기록한다. AI 세션은 그 시작일 뿐이다.
2. **병렬 스트림 인식** — 동시에 도는 세션들을 **레인(lane)** 으로 나눠 타임라인에 나란히 보여준다. (제품 정체성)
3. **로컬 온리 · 프라이버시** — 데이터는 100% 내 기기에만. 클라우드/텔레메트리 0. (신뢰 = 핵심 자산)

## 스코프

### 지금 (기록 최우선, 뾰족하게)
- 자동 캡처: **Claude Code → Kiro(CLI+IDE) → Gemini(웹)**
- 통합 저장: 로컬 SQLite + 전문검색(FTS5)
- 열람: 병렬 스트림 타임라인 · 전문검색 · 오늘의 요약(digest)
- 수동 기록(quick-add) 보조

### 나중 (확장)
- SaaS 커넥터: Linear · Slack · Jira · Figma · Notion (**Pro 유료**)
- AI 요약 다이제스트, 멀티기기 E2E 동기화(**Pro**)
- OS 레벨 캡처(활성 창/클립보드) — **opt-in**, 침습적이라 후순위
- Windows 지원

### 명시적 비(非)스코프 (지금 안 함)
- 팀 공유 / 협업 / 서버 대시보드 (로컬 온리 철학 위배)
- OS 전체 감시형 캡처 (프라이버시/무게 문제, 나중 opt-in만)
- 모바일

## 타깃 사용자

- 1차(도그푸드): 나 자신 — AI 툴을 병렬로 쓰는 개발자.
- 2차(판매): 여러 툴에 걸쳐 일하며(개발자·PM·디자이너) **프라이버시를 중시**하는 사람.

## 수익 모델 (요약, 상세는 06)

- **소스 공개**: MIT 오픈소스(ADR-0018 — 이전 계획은 클로즈드 프리미엄·소스 비공개였다).
- **무료 티어**: 로컬 AI 툴 캡처 + 타임라인 + 검색 + 수동기록 (그 자체로 완결).
- **Pro 구독**: SaaS 커넥터 + AI 요약 + (미래) E2E 동기화. → 커넥터의 지속적 유지보수가 구독의 근거.

## 성공 지표 (도그푸드 기준)

- **D1**: 하루 종일 켜두고 Claude Code/Kiro 세션이 자동으로 타임라인에 쌓인다.
- **W1**: "지난주에 그 프롬프트 뭐였지?"를 검색 3초 안에 찾는다.
- **M1**: 매일 아침 전날 digest를 보고 "어제 뭐 했는지" 회고가 된다.
- 판매 준비 신호: 내가 매일 안 켜면 불편할 정도로 습관이 됐을 때.

## 용어 (Glossary)

| 용어 | 뜻 |
|------|-----|
| **Event** | 캡처된 개별 활동 1건 (프롬프트, 응답, 툴사용, 메시지 등) |
| **Stream** | 하나의 세션/대화/작업 흐름. 타임라인의 **레인 1개**. (소스의 native session이 기본 단위) |
| **Source** | 캡처 출처 (claude_code, kiro_cli, kiro_ide, gemini_web, manual …) |
| **Capturer/Adapter** | 특정 소스를 감지·정규화해 인제스트로 보내는 모듈 |
| **Ingest** | 캡처 데이터를 받는 로컬 HTTP 엔드포인트(127.0.0.1) |
| **Digest** | 특정 기간(주로 하루)의 활동 요약 |
| **Lane** | 타임라인에서 겹치는 스트림을 세로로 분리한 행 |
