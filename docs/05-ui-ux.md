# 05 · UI / UX

설치형 데스크톱 GUI. **기록은 백그라운드 자동, 열람은 창을 열어서.**

## 앱 표면

- **메인 창**: React UI(아래 화면들).
- **메뉴바(트레이) 아이콘**: 상시 실행 표시, **소스별 캡처 헬스**(ok·지연·오류 점), 캡처 on/off 토글, 오늘 요약 바로가기, 창 열기.
- 앱 종료해도 트레이로 상주(설정에서 변경 가능) → 캡처 지속.
- **구현 상태(v1, `src-tauri/src/tray.rs`)**: 메뉴 = `LogRoom 열기` / `오늘 요약` / 구분선 / `캡처 일시정지`(체크박스) / 구분선 / `종료`.
  창을 닫아도 종료하지 않고 숨김 처리해 캡처(감시 스레드 + 인제스트 서버)가 계속되며, "열기"/"오늘 요약"/두 번째 실행 시 창을 다시 표시한다.
  일시정지 토글은 FE 설정과 트레이 체크박스가 `capture-paused-changed` 이벤트로 양방향 동기화된다.
  소스별 헬스 점을 트레이 아이콘 자체에 표시하는 것은 후속(현재는 헤더 배지에서만 제공).

## 화면 (M1 = ①②, 이후 확장)

### ① Today / Timeline (핵심 화면)
- **병렬 레인 타임라인**: 가로=시간축(오늘), 세로=레인(겹치는 스트림 분리 — 02의 레인 배치).
- 각 스트림 바: 소스 아이콘 + 제목 + 프로젝트 색상. 바 안/위에 이벤트 마커(프롬프트/툴사용).
- "지금 활동 중"(최근 15분) 스트림 상단 강조.
- 클릭 → 우측 패널에 **스트림 상세**(이벤트 목록/대화).
- 상단: 날짜 네비게이션, 소스/프로젝트/타입 필터, **캡처 헬스 배지**(소스별 마지막 캡처 시각).

### ② Search
- 상단 `⌘K` 전역 검색 → FTS5로 프롬프트/응답/제목 전문검색.
- 결과: 이벤트 스니펫(하이라이트) + 스트림/시간/소스. 클릭 → 해당 위치로.
- 필터: 소스, 기간, 타입, 프로젝트.

### ③ Stream Detail
- 한 세션의 전체 흐름(프롬프트→응답→툴사용) 대화형 뷰.
- 메타: 프로젝트, git branch, 모델, 총 토큰, 소요시간.

### ④ Digest ("오늘 한 일")
- 하루(또는 기간) 요약: 프로젝트별/스트림별 활동 집계, 이벤트 수, 토큰, 주요 프롬프트.
- M1은 **집계 기반**(규칙). AI 자연어 요약은 Pro/후속.

### ④-b 업무평가서 (요약 뷰 "평가" 스코프, ADR-0017)
- [분기 평가 | 월간 점검] 토글 + ◀ 기간 ▶. 분기는 달력 분기("2026년 3분기 (7~9월)").
- 입력(전부 선택): **평가 프로필**(직무·연차 구간·팀원 관리 — 비어 있으면 처음 한 번 인라인으로 묻고,
  설정 → AI 요약에서도 고친다), **포함할 프로젝트**(체크리스트, 제외 목록은 로컬 저장 — 새 프로젝트는
  기본 포함), **목표**(적으면 목표 대비로 평가).
- 결과는 보고서로 그린다(`ReviewReport.tsx`):
  - 머리: 제목, 부제(직무·연차·프로젝트·목표 유무), 근거 범위 한 줄
  - 숫자 타일: 활동일·요청·완료 이슈(중앙값)·기간 말 미완료(정체 수)·PR·리뷰. 0인 타일은 뺀다
  - 세 칸 카드: 잘한 것(초록)·못한 것 또는 밀린 것·막힌 것(주황)·채우면 좋은 것(파랑). 항목마다
    요지·설명·축 칩·"목표 외" 칩·근거 번호 칩을 달고, 칸 머리에 축별 개수를 적는다
  - 기록된 활동: 활동 추이 작은 막대 셋(요청·Slack·GitHub·Linear 활동·Linear 완료), 프로젝트 비중
    가로 막대(상위 6 + 기타), 표로 보기. "평가 근거가 아니라 맥락" 안내를 붙인다
  - 옵션: 시간·요일 분포 히트맵(기본 꺼짐, localStorage 저장)
- 복사는 평문(마크다운 기호 제거), 전송 내용 미리보기·수정, "AI 초안 — 제출 전 직접 다듬을 것" 안내.

### ⑤ Settings
- 소스 관리(on/off, 프로젝트 제외), 캡처 일시정지, 시크릿 스크럽 룰.
- 프라이버시(네트워크 투명성, 암호화), 라이선스(Pro), 데이터(export/삭제).

## 첫 실행 온보딩

설치 후 최초 실행 1회:
1. **환영 + 프라이버시 선언**: "모든 데이터는 이 기기에만" 명시(신뢰 확보).
2. **소스 선택**: 감지된 툴(Claude Code/Kiro CLI/IDE) 목록 → 켤 소스 선택. 제외할 프로젝트 지정 가능.
3. **권한 안내**(필요 시): 파일 접근이 막히면 안내(비샌드박스 직접배포라 대개 불필요, ADR-0009).
4. **backfill 여부**: 기존 세션 로그 소급 수집 선택(기간 지정).
5. 완료 → 트레이 상주 + Today 화면.

## 상호작용 / 상태

- **실시간 갱신**: Rust `event-ingested` emit → TanStack Query invalidate → 타임라인 즉시 반영.
- **데이터 접근**: 모든 읽기는 Tauri command(`list_events_by_day`, `search_events`, `get_stream`, `get_digest`). UI에서 SQL 직접 X.
- **상태 분리**: 서버데이터=TanStack Query, UI상태(필터/선택/패널)=Zustand.
- **키보드 우선**: `⌘K` 검색, `←/→` 날짜 이동, `j/k` 스트림 이동.
- **캡처 일시정지(M4)**: 헤더 `CaptureHealthBadge` 팝오버 하단의 토글 버튼("캡처 일시정지"/"캡처 재개")로
  즉시 켜고 끈다(재시작 불필요, 의미론은 04-privacy-security.md). 일시정지 중에는 지연(stale) 배지보다
  우선해 트리거에 "⏸ 캡처 일시정지됨"을 amber 톤으로 강조 — 몰래 꺼진 채로 잊히는 것을 막기 위해
  일부러 눈에 띄게 표시한다. 토글은 `get_capture_paused`/`set_capture_paused` 커맨드를 사용하고,
  성공 시 캡처 헬스·일시정지 상태 쿼리를 함께 invalidate한다.

## 디자인 방향

- shadcn/ui + Tailwind v4. **다크 우선**, 정보 밀도 높게(대시보드형), 차분한 톤.
- 소스별 색/아이콘 일관 팔레트(claude/kiro/gemini/manual).
- 성능: 이벤트 수천건 → 가상화(TanStack Virtual)는 실측 병목 확인 전 도입 보류 — 턴 트리 기본 접힘 +
  도구 그룹 점진 렌더(최초 50개 + "더 보기"로 +100씩)로 대응(2026-07). 타임라인은 SVG 레이어 최소 리렌더.
- 접근성: 대비 AA, 포커스 링, 키보드 완전 조작(추후 a11y-auditor 점검).
